# Future Technologies and Engineering Limited

Corporate website for [futuretechnologies.co.tz](https://www.futuretechnologies.co.tz).

## Stack

- Vite + React 19 + TypeScript (`.tsx`)
- React Router
- Tailwind CSS v4

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
```
